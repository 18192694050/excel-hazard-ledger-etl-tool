# excel-hazard-ledger-etl-tool
面向自然资源行业——地质灾害隐患点台账批量规整ETL工具

## 📌 项目背景
自然资源基层单位长期维护多版本地质灾害隐患Excel台账，存在表格模板不统一、大量合并单元格、文本脏数据、点位重复、新旧台账人工对账工作量巨大等痛点。
本项目基于 SpringBoot + Apache POI 开发Web接口服务，实现多Sheet台账自动解析、隐患编号关联对账、数据清洗校验、标准化成果导出、PostgreSQL事务批量入库，用于地质灾害台账常态化数据治理。

> ⚠️ 数据合规声明：仓库仅开放业务逻辑源代码，**涉密原始隐患点位、地理坐标原始文件不上传仓库**，严格遵守地理信息数据保密要求。

## 🛠 技术栈
- 核心框架：SpringBoot
- Excel处理：Apache POI（SXSSF流式读写，解决大文件OOM）
- 数据库：PostgreSQL（预留PostGIS空间数据扩展接口，支持隐患点位空间分析拓展）
- 持久层：MyBatis
- 工具包：Hutool、Lombok
- 特性：全局异常捕获、数据库事务控制、业务日志记录

## ✨ 核心功能
1. 支持多Sheet Excel批量上传，兼容并解析合并单元格
2. 依据**隐患编号**作为唯一主键，实现新旧台账自动对账，区分新增、更新、灭失隐患点
3. 内置脏数据清洗规则：首尾空格清理、空值过滤、异常文本规范化、重复数据检测
4. 数据校验拦截，异常数据统一收集，支持导出脏数据明细Excel
5. 自动生成标准化格式的成果台账Excel
6. PostgreSQL批量事务写入，异常自动回滚，保障批量导入的数据一致性
